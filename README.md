## ⚡ Quickstart

### Daily Session Commands

- **Orientation**: Check session state and active tasks
  ```bash
  oracle-skills recap
  ```
- **Context Search**: Search history and past learnings
  ```bash
  oracle-skills trace "search query"
  ```
- **Retrospective**: End session with reflective summary
  ```bash
  oracle-skills rrr
  ```

## 📜 Principles

1. **Nothing is Deleted** — Append-only state, preserving full execution history.
2. **Patterns Over Intentions** — Empirical evidence over abstract assumptions.
3. **External Brain, Not Command** — Empowering human decision sovereignty.
4. **Bampenpien (บำเพ็ญเพียร)** — Continuous focus and rigorous test verification.
5. **Rule 6: Transparency** — Always clear, honest AI attribution.
